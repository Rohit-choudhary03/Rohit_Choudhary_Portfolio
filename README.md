## ⚡ Tech Stack & Features

- **Built with**: Pure HTML5, Modern CSS3, Vanilla JavaScript (ES6+) — Zero external runtime dependencies or build steps.
- **Theme**: Modern Dark Theme with Electric Blue & Cyan accents, with an interactive **Light/Dark Mode toggle** saved via `localStorage`.
- **Responsive**: Mobile-first responsive layout (smartphones, tablets, and desktops).
- **Animations**:
  - CSS-animated background particles and smooth gradient shifts
  - Typing effect cycling through engineering roles
  - Smooth scroll spy with section highlights and scroll progress indicator
  - Scroll reveals powered by the Intersection Observer API
  - 3D card tilt effects
- **Interactive Sections**:
  - **Hero**: Tagline, dynamic typing effect, CTA buttons, and downloadable resume
  - **Skills**: Visual progress meters across Languages, Frameworks, Databases, Tools & Core Competencies + Soft Skills badges
  - **Projects**: Category filterable grid (Full Stack, Data Analytics, AI / ML) with GitHub repo links
  - **Experience & Education**: Timeline with Oston Technology internship and SRM Institute B.Tech details
  - **Certifications**: AWS Certified AI Practitioner, Oracle Java SE 17 Developer, SAP Certified Data Analyst
  - **Blog / Articles**: Featured engineering write-ups
  - **Contact**: Interactive contact form with floating labels & feedback states
  - **Resume**: Integrated downloadable vector PDF (`Rohit_Choudhary_Resume.pdf`)

## 🚀 How to Deploy to GitHub Pages

Deploying your portfolio to GitHub Pages takes under 2 minutes:

### Option A: User Pages (`username.github.io`)
1. Create a new repository on GitHub named exactly:
   ```
   Rohit-choudhary03.github.io
   ```
2. In your terminal, run:
   ```bash
   git add .
   git commit -m "Initial commit: Rohit Choudhary portfolio website"
   git branch -M main
   git remote add origin https://github.com/Rohit-choudhary03/Rohit-choudhary03.github.io.git
   git push -u origin main
   ```
3. Your site will automatically go live at **`https://rohit-choudhary03.github.io`**!

### Option B: Project Pages (`username.github.io/portfolio`)
1. Create a repository named `portfolio` on GitHub.
2. Push your code:
   ```bash
   git add .
   git commit -m "Initial commit: Rohit Choudhary portfolio website"
   git branch -M main
   git remote add origin https://github.com/Rohit-choudhary03/portfolio.git
   git push -u origin main
   ```
3. Go to **Repository Settings** > **Pages** > Under "Branch", select `main` and `/ (root)` > Click **Save**.
